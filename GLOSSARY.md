# Skills kit

The personal kit of agent skills, and the coding standards a new project starts with.

## Language

**Coding standard**:
The rules a project records for how its code is written, which a review applies to a change in that project.
_Avoid_: skill, 全局规范

**Stack**:
A family of projects that share one coding standard. Gin and React are the two stacks.
_Avoid_: Go, 脚手架, 模板

**Template**:
The files copied into a new project so that stack's coding standard is present there.
_Avoid_: skill
